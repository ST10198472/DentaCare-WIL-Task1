## Project Description
DentaCare is a dentist management system designed to streamline appointment scheduling, patient management, and service offerings. The system includes both desktop and mobile wireframe prototypes to demonstrate a user-friendly interface for patients and dental practitioners.

## Folder Structure
```
DentaCare-WIL-Task1/
├── index.html              # Homepage
├── pages/
│   ├── login.html          # Login page
│   ├── book.html           # Appointment booking page
│   ├── dashboard.html      # Dashboard page
│   ├── services.html       # Services page
│   ├── mobile-home.html    # Mobile homepage prototype
│   ├── mobile-book.html    # Mobile booking prototype
│   ├── mobile-appointments.html  # Mobile appointments prototype
│   └── mobile-services.html      # Mobile services prototype
└── README.md               # Project documentation
```

## How to View the Pages
1. Clone or download this repository
2. Open `index.html` in your web browser to access the homepage
3. Navigate to the `pages/` folder to view individual pages:
   - Desktop versions: `login.html`, `book.html`, `dashboard.html`, `services.html`
   - Mobile prototypes: `mobile-home.html`, `mobile-book.html`, `mobile-appointments.html`, `mobile-services.html`
